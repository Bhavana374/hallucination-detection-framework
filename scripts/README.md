# Command-Line Scripts Directory

Automated executable scripts for data ingestion, model training, evaluation, and pipeline deployment.

## Planned Scripts
- `download_data.py`: Secure download and caching of benchmark datasets.
- `train_baseline.py`: Train and evaluate TF-IDF + LR/RF baselines.
- `train_transformer.py`: Fine-tune BERT and DeBERTa architectures.
- `train_hybrid.py`: Train the Random Forest hybrid classifier.
- `run_ablation.py`: Execute the comprehensive ablation suite.
- `run_evaluation.py`: Generate consolidated metrics and LaTeX tables.
