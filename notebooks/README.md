# Jupyter Notebooks Directory

This directory contains research notebooks for exploratory data analysis, interactive model debugging, and evaluation visualizations.

## Planned Notebooks
- `01_dataset_exploration.ipynb`: Statistical analysis and distribution visualization.
- `02_retrieval_analysis.ipynb`: Vector index quality and top-k retrieval evaluation.
- `03_feature_analysis.ipynb`: Correlation and discriminative power of hybrid features.
- `04_model_comparisons.ipynb`: ROC/PR curves and comparative analysis.
